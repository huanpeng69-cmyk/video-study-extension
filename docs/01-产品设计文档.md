# 视频学习助手｜产品设计文档

> 版本：v0.1 · 日期：2026-10-19  
> 状态：需求与方案建议稿，尚未实现。本文中的性能、质量及成功率均为**拟定验收目标**，不是实测结果。  
> 配套：[技术方案](02-技术方案.md) · [开源调研与依据](03-开源调研与依据.md)

## 1. 产品结论

做一个 **Chrome / Edge 浏览器扩展**：用户在 B站观看视频时，打开侧边栏，获取带时间戳的字幕，调用自己配置的 AI API 进行翻译与总结，把个人理解与原文证据一起保存到本地，随时导出 Markdown。

首版要完成的核心闭环：

**当前视频 → 字幕 → 可追溯的翻译/总结 → 个人笔记 → 搜索与回看。**

“视频获取”在首版中指识别当前视频、分 P、来源与播放位置，不代表下载完整视频文件。“本地优先”指数据归属和存储方式；启用云端模型后，选定的字幕内容仍会发送给该模型服务商。

### 1.1 已由用户确认

| 项目 | 确认内容 |
|---|---|
| 原始痛点 | 经常看视频，但容易忘记讲了什么，希望提取字幕用于记录 |
| 核心流程 | 视频获取、字幕提取、翻译总结、记录笔记 |
| 产品形态 | Chrome / Edge 浏览器扩展 |
| 首个视频平台 | B站 |
| 笔记归属 | 工具内本地保存，支持 Markdown 导出 |
| AI 使用方式 | 用户自行配置 API，例如 Agnes APIHub |
| 本次交付 | 产品设计文档与技术方案，结合成熟开源项目调研；不进入应用编码 |

### 1.2 本文建议，尚需使用验证

- 首版先服务个人自用，免账号、免自建服务器。
- 默认输出简体中文，提供英文目标语言；中文原字幕允许直接总结，跳过翻译。
- 首版支持已有字幕及 SRT/VTT 文件导入；无字幕视频的语音转写后置。
- 首版先做学习记录与简单复习问题，不做完整知识库、向量检索或间隔复习系统。
- 先通过本地开发者模式使用；公开上架另设权限、隐私和平台条款检查。

## 2. 用户与使用场景

### 2.1 核心用户任务

> 当我看完一段教程或知识视频，我希望留下一份带原文依据和时间位置的笔记，下一次遇到问题时能快速找回，而无需重新看完整个视频。

| 场景 | 用户动作 | 产品应提供的结果 |
|---|---|---|
| 看中文教程 | 获取字幕并生成摘要，补充个人理解 | 章节纲要、关键步骤、对应原视频位置 |
| 看外语视频 | 选择字幕轨道，翻译成中文 | 原文/译文逐条对照，术语尽量一致 |
| 长视频学习 | 按段处理，分几次完成笔记 | 已完成段落保留，可继续处理未完成部分 |
| 事后查找 | 搜索标题、标签或自己的笔记 | 找到资料，并回到相关字幕/视频位置 |
| 模型不可用 | 继续手动记录，稍后再生成 | 原字幕和笔记不受 AI 接口失败影响 |
| 没有可用字幕 | 查看原因或导入已有字幕文件 | 明确下一步，不生成与视频无关的假摘要 |

### 2.2 不将哪些内容当作已知事实

字幕未必包含画面里的公式、代码、图表、演示步骤。首版生成物须标注“基于字幕整理”，不宣称理解了全部视频画面。字幕本身可能有识别错误，AI 的归纳也需要用户核对。

## 3. 参考产品与差异化

HoverNotes 的商店说明强调边看边记、截图与时间戳、AI 视频理解、本地 Markdown/Obsidian 保存。本次已阅读其产品介绍，未安装或实测扩展；这些属于产品方描述，详见调研文档。

本项目借鉴它的学习流程，首版做以下取舍：

| 方向 | 本项目的选择 | 用户价值 |
|---|---|---|
| 主要输入 | 优先使用文本字幕 | 处理成本更容易估计，也方便核对依据 |
| AI 服务 | 自带 API Key，可修改服务地址和模型 | 用户自行控制模型、账户与费用 |
| 笔记存储 | 扩展本地存储 + 通用 Markdown | 无需安装 Obsidian，也不绑定云端账户 |
| 结果可信度 | 摘要要绑定原字幕引用 | 从结论回到原文，减少“总结看着对但无法核实” |
| 无字幕视频 | 首版明确提示，提供文件导入 | 不把高成本转写隐藏在一次点击之后 |
| 手写笔记 | 与 AI 生成内容分开保存 | 重新生成摘要不会覆盖用户的个人理解 |

## 4. 范围与优先级

### 4.1 首版必做（P0）

| 编号 | 功能 | 范围与行为 | 核心验收 |
|---|---|---|---|
| F01 | 当前视频识别 | 识别 B站普通视频页的标题、BV 号、当前 CID/分 P、链接及播放位置 | 分 P 切换后不会把字幕和笔记写入上一 P |
| F02 | 字幕获取 | 列出可读取字幕轨道；区分语言及已知的人工/自动来源；保留原始时间轴 | 无字幕、需登录、接口失败分别提示；未知来源不强行标注 |
| F03 | 字幕文件导入 | 导入 UTF-8 SRT/VTT，支持 BOM、换行、多行文本；绑定当前视频/分 P | 格式错误给出行或条目位置，不静默丢弃内容 |
| F04 | 字幕阅读与定位 | 搜索字幕、点击时间戳跳转、选取原文加入笔记 | 原始时间轴不被翻译或段落合并改变 |
| F05 | 双语翻译 | 当前选段或全文翻译；默认中文，可选择英文；显示原文与译文 | 每条译文对应有效原字幕 ID；缺失段明确标记 |
| F06 | 学习总结 | 内容概览、章节纲要、核心知识点、术语、3–5 个复习问题（内容不足时允许更少） | 实质性摘要条目可回到原文；不编造时间点 |
| F07 | 手动笔记 | Markdown 编辑、引用原文/译文、添加个人理解、选择性插入 AI 摘要 | 自动保存有状态提示；重新生成不覆盖手写内容 |
| F08 | 本地资料库 | 按视频/分 P 保存，支持标题、标签、笔记正文搜索及最近更新排序 | 重启浏览器后内容可找回；同一资料不因重复打开而重复创建 |
| F09 | 导出 | Markdown 导出，可选择附带全文字幕/译文；原文可导出 SRT | 包含来源、分 P、时间链接；无 API Key、Cookie 或带凭证的字幕 URL |
| F10 | 自接 API | 服务预设/自定义 Base URL、模型 ID、API Key、测试连接 | 能显示实际请求目标；错误不混成“生成失败” |
| F11 | 长任务控制 | 分段进度、取消、失败段重试、恢复已完成结果 | 关闭面板后不宣称后台持续运行；重开可继续未完成段 |
| F12 | 本地备份恢复 | 导出/导入版本化 JSON 备份；恢复前预览冲突和数量 | 备份不包含密钥；格式错误不破坏当前资料 |
| F13 | 权限与隐私 | 模型域名按需授权；首次发送前告知数据范围；支持删除资料、清除密钥 | 不请求 Cookie 读取权限，不自动上传视频或个人笔记 |

### 4.2 后续增强（P1，需另行确认）

- 无字幕视频的语音转写：先考虑用户导入自己有权使用的音频/视频文件，再选择本地或云端 ASR。
- 知识卡片、复习提醒、跨视频关联。
- 一键写入用户授权的 Obsidian 目录。
- 自定义术语表、更多目标语言、已有字幕的对齐编辑。
- 播放列表及多视频任务队列。

### 4.3 首版明确不做

完整视频下载、后台录屏/录音、付费内容访问绕过、YouTube/任意课程站适配、截图视觉理解、OCR、云同步、多人协作、向量数据库、浏览器关闭后继续执行任务。字幕源接口不是 B站对本扩展的官方服务承诺，不能对所有视频作可用性保证。

## 5. 信息架构与页面设计

### 5.1 页面组成

| 页面 | 入口 | 核心内容 |
|---|---|---|
| 学习侧边栏 | 点击扩展图标 | 当前视频卡片、字幕/总结/笔记三个页签、任务状态 |
| 本地资料库 | 侧边栏的“资料库” | 搜索、标签、最近记录、备份/恢复、删除 |
| API 与偏好设置 | 齿轮按钮 | 模型配置、密钥策略、连接测试、目标语言、域名授权 |
| 完整学习页 | “在独立标签页打开” | 复用侧边栏组件，适合长视频与大段编辑；仍属同一扩展 |

### 5.2 侧边栏布局

建议从 360–480 px 宽度开始设计，支持键盘操作及缩放，不遮挡 B站播放器。

1. **顶部视频卡片**：标题、分 P、时长、来源链接、重新识别按钮。
2. **状态条**：当前字幕轨道、获取状态、本地保存状态。
3. **字幕页签**：轨道选择、搜索、原文/双语切换、时间戳列表、选段翻译/加入笔记。
4. **总结页签**：生成范围、概览、章节、知识点、复习问题；每条引用可查看原文并跳转。
5. **笔记页签**：Markdown 编辑区、预览、插入选段、插入摘要、导出。
6. **底部任务区**：例如“翻译 4/12 段”，提供取消/继续；同时显示使用的模型和已知 Token 用量。

用户手动滚动字幕时暂停自动跟随，显示“回到当前播放位置”；不因播放器每次更新时间而抢走编辑焦点。

### 5.3 首次使用

1. 在 B站普通视频页打开扩展，说明支持范围。
2. 获取字幕；未配置 AI 时也允许阅读、手写和导出。
3. 首次点击“翻译/总结”才引导配置服务地址、模型和自己的 API Key。
4. 展示将发送的字幕范围、服务域名、可能产生的费用及权限申请。
5. 用户同意后运行；完成结果进入本地资料库。

首次使用不强制注册本工具账号，也不要求把 API Key 发给开发者。

## 6. 主流程与异常流程

### 6.1 正常流程

1. 识别当前视频和分 P，查找已有本地记录。
2. 用户点击“获取字幕”，选择字幕语言/轨道。
3. 展示原字幕、条数、来源和时长，先保存本地版本。
4. 用户选择直接总结，或先翻译后对照阅读。总结默认仍以原字幕为依据，减少二次转述误差。
5. 按段生成结果，显示进度；有效结果逐段保存。
6. 用户将感兴趣的内容加入个人笔记，可修改和标注。
7. 自动保存完成后显示“已保存”；可导出 Markdown 或回到资料库。

### 6.2 必须设计的状态

| 状态 | 展示文案方向 | 可执行动作 |
|---|---|---|
| 不支持的页面 | “请在 B站普通视频页使用，或打开已有本地笔记” | 打开资料库 |
| 页面尚未就绪 | “正在等待播放器信息” | 有上限地重试、重新识别 |
| 需要登录 | “该字幕可能需要登录 B站后读取” | 用户自行登录，再次获取 |
| 没有字幕 | “当前未发现可读取的字幕，首版不包含语音转写” | 导入 SRT/VTT、继续手写 |
| 无法判断是否有字幕 | “字幕信息读取失败，尚不能确定是否有字幕” | 重试、查看脱敏错误、导入文件 |
| 已有字幕发生变化 | “检测到新的字幕版本” | 保留旧版、另存新版；旧笔记引用仍可查看 |
| API 未配置/权限拒绝 | “AI 尚未连接，本地笔记功能仍可用” | 配置、重新授权、取消 |
| Key 无效/无额度 | 分别提示鉴权失败或余额/额度不足 | 修改配置、查看服务商控制台 |
| 限流/暂时故障 | 显示等待时间或失败段 | 取消、稍后重试 |
| 部分生成失败 | “8/10 段已完成，2 段未完成” | 只重试未完成段；摘要标注不完整 |
| 面板关闭/页面被丢弃 | 重开时提示“上次任务中断” | 恢复，不重复已保存结果 |
| 切换视频/分 P | 告知当前任务仍绑定原视频 | 查看新视频或回到原任务，不自动混用内容 |
| 保存失败/存储空间不足 | 持续显示“未保存”警告 | 复制/导出当前内容、清理后重试 |

## 7. 翻译与总结规则

### 7.1 翻译

- 原字幕保持只读；译文作为独立结果保存。
- 时间戳、数字、链接、代码及专有名词尽量保留语义，不自行补充未出现的信息。
- 译文返回顺序变化时按字幕 ID 重新对齐；不能用数组位置猜对应关系。
- 原文、译文分开复制和导出，自动字幕标签继续保留。
- 全文翻译前显示范围和预计批次；用户可仅翻译选段。

### 7.2 总结

每份总结包含：

| 区域 | 内容规则 |
|---|---|
| 内容概览 | 概括主题和学习目标；能关联覆盖这些结论的字幕范围 |
| 章节纲要 | 按原字幕顺序组织，可点击回看，不强凑固定章节数 |
| 核心知识点 | 每个知识点附原字幕引用；区分陈述、操作建议和讲者观点 |
| 术语说明 | 仅整理视频中出现的术语；额外解释如被允许，必须另标“补充” |
| 复习问题 | 基于已有内容提问，答案关联字幕；用于主动回忆 |
| 来源与生成信息 | 视频、分 P、字幕版本、模型、生成时间、是否为部分结果 |

首版默认禁止外部知识补充、联网检索及工具调用。模型输出先校验后展示；引用真实存在只证明可追溯，并不自动证明推理正确。

## 8. 笔记与资料库规则

### 8.1 一份笔记的内容

建议导出顺序：视频标题与来源 → 内容概览 → 章节/知识点 → 我的笔记 → 复习问题 → 可选原文/译文附录。

元信息包含 BV 号、CID/分 P、字幕语言与来源、创建/更新时间、标签。AI 结果还记录模型和字幕版本。导出不写入密钥、鉴权头、浏览器身份信息或临时字幕下载令牌。

### 8.2 编辑与保存

- 手动笔记和 AI 生成结果是两类记录；“加入笔记”才创建可编辑副本。
- 自动保存建议在停止输入约 800 ms 后触发；只有本地事务成功才显示“已保存”。
- 显式保存、切换资料、导出前先尝试提交待保存修改。窗口意外关闭时不承诺最后一瞬间尚未提交的按键一定恢复。
- 检测到另一窗口更新同一笔记时提示冲突，保留双方内容，避免后写无提示覆盖。
- 删除资料前确认，明确删除范围：字幕、译文、摘要和相关笔记；用户此前导出的外部文件不会被删除。

### 8.3 本地不等于备份

扩展数据属于当前浏览器配置文件，卸载、损坏或清理资料都可能导致丢失。首版提供 Markdown 导出和不含密钥的 JSON 备份；提示用户定期备份，但不在未授权的情况下自动写入外部目录。

恢复先预览并校验，默认合并；遇到相同 ID 的不同内容，创建冲突副本或由用户选择。不得通过一次失败的导入清空现有资料。

## 9. API 配置与隐私体验

### 9.1 配置表单

| 字段 | 设计 |
|---|---|
| 服务类型 | 首版 OpenAI Chat Completions 兼容接口；Agnes 为预设之一 |
| Base URL | Agnes 预设 `https://apihub.agnes-ai.com/v1`，支持用户修改 |
| 模型 ID | Agnes 可用文档中的 `agnes-2.5-flash` 作为初始示例，最终以用户账户实际可用模型为准 |
| API Key | 遮罩输入、可清除；默认仅本浏览器会话保存 |
| 本机记住密钥 | 可选，明确说明本地持久化不等于系统密钥库加密；不默认开启 |
| 目标语言 | 默认简体中文，提供英文 |
| 测试连接 | 发送不含用户字幕的短测试，先提示可能消耗少量额度 |
| 诊断结果 | 显示最终服务域名、模型、耗时、HTTP 状态及脱敏原因 |

模型列表自动发现不是使用前提：服务商可能不提供模型列表接口，必须允许手动填写模型 ID。

### 9.2 首次发送前的确认

建议告知：

> 即将把本次选定的字幕文本发送至 **{服务域名}**，使用 **{模型}** 进行 **{翻译/总结}**。视频文件、B站 Cookie、你的其他笔记不会发送。服务商可能计费并按其隐私政策处理数据。是否继续？

首次使用、切换服务商或改变发送数据种类时重新确认。AI 不可用时，保留全部本地功能。

### 9.3 费用呈现

有返回用量时显示输入/输出 Token；缺失时标注未知。费用仅在用户设置或官方核对过单价后估算，并标注估算时间；不伪造精确账单。不通过多 Key 轮换规避服务商限流。

## 10. 验收与效果衡量

### 10.1 首版验收用例

| 编号 | 用例 | 通过条件 |
|---|---|---|
| A01 | 已知有字幕的普通视频 | 成功获取字幕并保留时间轴，能导出并回看 |
| A02 | 多 P 视频及站内切换 | 当前 CID 正确；旧请求晚到不污染新页面 |
| A03 | 无字幕/需登录/接口错误 | 三种状态能区分，无法判断时不误报“无字幕” |
| A04 | SRT/VTT 导入 | 正常、多行、BOM、异常时间轴样本都有明确结果 |
| A05 | API 正常和异常 | 合法响应可显示；401/402/429/超时各有处理路径 |
| A06 | 翻译对齐 | 每条完成译文都对应有效原文 ID；无静默漏段/错位 |
| A07 | 总结引用 | 所有展示的引用 ID 有效；非法引用使该结果校验失败 |
| A08 | 人工抽查质量 | 至少 3 类视频各抽查 10 个摘要条目，记录是否被字幕支持；重要事实错误须修正后发布 |
| A09 | 关闭、重开、取消 | 保存已完成段，恢复不重复已完成段；取消后停止新请求 |
| A10 | 笔记保存与导出 | 保存后重启可恢复；重新生成不覆盖手写；导出无密钥 |
| A11 | 备份与冲突 | 有效备份可恢复；损坏/高版本备份拒绝或只读预览，不破坏旧数据 |
| A12 | 权限与恶意输入 | 页面不能读取 Key；字幕/Markdown 中脚本和恶意链接不能执行 |
| A13 | Chrome / Edge | 在记录具体版本的两款浏览器上完成 A01、A05、A09、A10 |

### 10.2 建议性能目标

以下是首版测试范围和预算，不代表无限支持：

- 单次学习任务先覆盖时长不超过 2 小时、字幕不超过 20,000 条的材料；文件导入上限建议 5 MiB。超过限制应明确拒绝或要求分段，不截断后假装全文成功。
- 500 条视频/分 P 元数据的资料库，常用标题/标签/笔记搜索目标为 500 ms 内；具体硬件和数据规模写入测试报告。
- 侧边栏本地内容冷开目标 2 秒内；字幕列表只渲染可见区域。
- 正常设备上，停止输入后的自动保存确认目标在 1.5 秒内；磁盘/配额异常单独处理。
- AI 耗时受网络、模型、额度及文本量影响，首版不承诺“一小时视频几秒总结”。以可见进度、可取消、可恢复作为硬性标准。

### 10.3 自用效果验证

连续使用 1–2 周，记录：能否完成“获取→笔记→导出”；回找某个知识点用了多久；摘要是否值得保留；用户实际修改了哪些内容。优先依据这些反馈调整流程。首版不默认上传行为统计。

## 11. 建议实施顺序

| 阶段 | 内容 | 退出条件 |
|---|---|---|
| M0 可行性验证 | 真实 B站字幕获取、分 P、真实自带 Key 请求、扩展跨域权限 | 两个核心外部依赖各有成功样本和失败记录 |
| M1 非 AI 闭环 | 视频识别、字幕阅读/导入、手写、本地存储与导出 | 不配置 API 也可独立使用 |
| M2 AI 闭环 | 模型配置、翻译、带引用总结、用量和错误提示 | 可追溯结果及失败恢复通过验收 |
| M3 使用加固 | 备份、冲突、长视频、双浏览器、安全与文档 | A01–A13 完成；未通过项明确列为限制 |

不把上架审核通过、免费额度长期有效或 B站接口长期稳定当作开发者可控制的里程碑。

## 12. 实施前还需要的输入

这些不阻碍当前方案交付，但会影响实际验证：

1. 2–3 个你有权观看的常用 B站视频链接，最好包含多 P 和有外语字幕的样本。
2. 你在自己的扩展设置中填写可用 API Key，并确认该账户可用模型。**不需要在对话或文档里提供完整 Key。**
3. 是否存在“绝不能发送到云端”的课程/培训材料；这类材料默认只允许本地记录，后续再讨论本地模型。
4. 首版是仅个人使用，还是计划公开上架。本文按个人自用优先设计，公开分发需增加相应合规检查。
